## Standing gotchas (all of these bit during this session)
- **`pytest` piped to `tail` hangs here.** Redirect to a file and `tail` the file.
- **`uvicorn --reload` and Vite HMR are unreliable under OneDrive.** Restart the API
  manually after backend edits or it silently serves stale code.
- **Never let a unit test call `run_matchday`.** One did, and because cups now join the
  plan it made a live ESPN call *and spawned a real headful FBref backfill*, ingesting two
  FA Cup ties for real (141s). `tests/test_matchday.py::_isolate` now patches
  `run_backfill.run`, `espn_pending` and the team-row pass.
- **Git Bash mangles `/F`-style flags** (`taskkill /F /IM ...` becomes a path). Use the
  PowerShell tool for Windows CLI flags.
- Browser-pane screenshots need the pane displayed; `get_page_text` works regardless.
- MCP `postgres` points at the wrong DB — query via `backend/.venv` + `SessionLocal()`.

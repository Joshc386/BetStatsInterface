## The bug that was live this morning
`matchday` exited 1 every day from 18 Aug. Cause: soccerdata caches
`~/soccerdata/data/FBref/seasons_<league>.html`, and copies taken in the off-season do **not** list the
new season, so every FBref read died with `KeyError: '2627'`. The watchdog mislabelled it "remaining
fixtures likely unmatched on FBref" — wrong; once refreshed the run linked 12 fixtures, 0 unmatched.

Fixed by moving the four stale caches aside (PL, Championship, FA Cup, EFL Cup) so soccerdata
re-fetched them, then a supervised run ingested all 12 pending Championship fixtures (379 player rows,
14–17 Aug). Full write-up in `docs/season-rollover-2627.md` → "What actually bit"; now rollover step 4
in `CLAUDE.md`. Stale-cache backups are in this session's scratchpad only (disposable).

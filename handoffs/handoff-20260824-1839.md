## ADR 0015 reversed itself mid-session — read this before the ADR
The first accepted draft chose **FBref** as the fallback source and was
**superseded the same day** by the ESPN version. The superseded file was deleted
(both were untracked, nothing lost). If anything reads oddly, that is why.

What killed FBref, measured live on 2026-08-23: a 12:00 kick-off that finished
~14:00 still had **no match report two hours later**, while ESPN had complete
stats within ten minutes. FBref is also Tier 2 supervised and covers only the
top two tiers. **Do not re-propose FBref for team data** — it is the slowest of
the three sources, not the fastest.

**ESPN cannot take player data** and this is settled: no per-player `tackles`
at all, and `minutes` only derivable from substitution clocks. **Appearance** is
defined as minutes > 0 and `per_90` divides by `minutes_total`.

## Standing gotchas (this session's additions in bold)
- **`&&` is a parse error** in the user's PowerShell 5.1.
- **Git Bash mangles `cmd //c run_x.cmd`** — it silently does not run. Use
  PowerShell: `& cmd.exe /c "<abs path>"`.
- **Tests pass by luck off live DB state.** Five instances found this session
  (`test_stats`, `test_table` ×2, and two of my own). **~20 unordered `LIMIT 1`
  sites remain across 7 test files**; 14 test files touch the live DB. A
  migration that rewrites the table changes which row they get, and the failure
  looks exactly like a broken feature. This is the best-value cleanup left.
- **The modal notifier corrupts its own health signal** — Last Run Result is
  trustworthy only when 0; otherwise read the log.
- `pytest` piped to `tail` hangs — redirect to a file.
- `uvicorn --reload` and Vite HMR are unreliable under OneDrive.
- **Screenshots need the Browser pane displayed**; `get_page_text` works anyway.
- **Vite takes ~5.5s to boot** — the preview tab loads before it is ready;
  navigate again.
- MCP `postgres` points at the wrong DB — query via `backend/.venv` +
  `SessionLocal()`.

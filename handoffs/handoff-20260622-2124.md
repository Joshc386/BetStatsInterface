## THE key context: FBref scraping (read `memory/player-data-fbref-blocked.md` first)
FBref is Cloudflare-walled. After much pain, the working recipe is proven:
- **VPN must be OFF** (Surfshark/WireGuard — Cloudflare blocks the VPN exit IP). This was the root cause of multi-hour hangs.
- **Use ONE persistent headful session**: `sd.FBref(leagues=..., seasons=..., headless=False)`, reuse the instance across all fetches. Cloudflare is solved once, then **~14s per fresh match**. PL last-2-seasons (~760 matches) ≈ **~3 hours**.
- **Do NOT** use subprocess-per-fetch (`ingestion/fbref_fetch.py`) for the backfill — it re-pays the ~2min Cloudflare tax every call. That runner is for bounded *isolated testing* only.
- Player stat type `summary` (one fetch/match) yields the whole catalogue: `min, Sh, SoT, Fls, Fld, TklW, CrdY, CrdR, Gls, Ast`. (`tackles ← TklW`; no `second_yellows`.) Fetch one match via `read_player_match_stats("summary", match_id=<schedule game_id>)`.
- **Championship schedule fetch fails even headful** — defer/skip; PL-only for now (user agreed).
- Orphan cleanup: `uc_driver.exe` detaches from the process tree — kill it by image name (`taskkill /F /IM uc_driver.exe /T`), not just the tree.

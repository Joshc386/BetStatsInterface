## Standing gotchas
- **`&&` is a parse error in the user's shell.** Use `;`, or absolute paths and no `cd`.
- **The modal notifier corrupts its own health signal.** `notify_failure.ps1` uses a blocking
  `MessageBox::Show`, so on failure the wrapper hangs, the task hits `ExecutionTimeLimit`
  (PT15M) and Task Scheduler reports **267014 (TERMINATED)** instead of the real exit code.
  **Last Run Result is trustworthy only when it is 0 — otherwise read the log.**
- **`pytest` piped to `tail` hangs here.** Redirect to a file and `tail` the file.
- **`uvicorn --reload` and Vite HMR are unreliable under OneDrive.** Restart manually.
- **Never let a unit test call `run_matchday`** — `tests/test_matchday.py::_isolate` exists
  because one did and ingested two FA Cup ties for real.
- **Watch for tests that pass by luck off live DB state.** Two did this session. Also:
  an `audit=fn` **default argument binds at def time**, so monkeypatching the module
  attribute silently does nothing — resolve inside the function.
- **Import cycles hide behind import order.** `tests/test_import_hygiene.py` now imports each
  entry point in a **subprocess**; in-process checks cannot catch them.
- MCP `postgres` points at the wrong DB — query via `backend/.venv` + `SessionLocal()`.
- Browser-pane screenshots need the pane displayed; `get_page_text` works regardless.

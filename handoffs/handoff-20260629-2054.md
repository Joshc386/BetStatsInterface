## Key facts the next session needs (not obvious from code)
- **Squad membership rule:** a club's Recent squad = players whose **`MAX(date)` appearance** is for that club — NOT the stored `current_team_id` (last-written, not chronological — see ADR 0006). Anchor: **Adam Armstrong (id 7634)** has 98 Southampton apps but his last game was for **Wolves (id 96)**, so he is in Wolves' squad, not Southampton's. Wolves squad-form is the best live test target.
- **Raw-rows pattern (ADR 0005/0006):** `/teams/{id}/squad-form` and `/fixtures/compare` return raw rows; the client aggregates with the unit-tested `frontend/src/lib/aggregate.ts` `summarise()` (it now exposes `n` = non-null count, the hit-rate denominator). `entity_summary` (Python) stays the regression oracle — keep its default-arg behaviour stable.
- **min_minutes** is **player-only** (teams have no minutes); applied before the `LIMIT n` ("his last N games of ≥X mins").

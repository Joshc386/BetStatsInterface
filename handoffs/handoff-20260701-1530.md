## Gotchas that cost time (now in memory — read them)
- **`read_schedule` carries team NAMES + `game_id` only — no team fbref_ids** (confirmed in soccerdata source). That is *why* cups create fixtures/opponents at ingest time (ids come from the match page via `parse_team_ids`, paired back by `pair_team_ids`). → `memory/cups-internationals-sourcing.md`.
- **One-shot cup fetches HANG on Cloudflare** — even `force_cache` does online season-discovery when you *select* a cup league. I hit this twice this session (the exact trap the memory warned about). Cup fetches must ride the watchdog. Merely having the cup in config is fine; *selecting* it is what fetches.
- **`uvicorn --reload` serves STALE code** (OneDrive). Plain uvicorn + manual restart. → `memory/uvicorn-reload-stale.md`.
- **No FastAPI TestClient** (`httpx` absent) — call route handlers directly with every `Query()` param explicit.

## Recurring lesson — TEAM NAME MAPPING (do not repeat)
FBref spells clubs **two ways** and a backfill hits both: schedule page = short ("QPR", "West Brom"), player-match scorebox = full ("Queens Park Rangers", "West Bromwich Albion"). `resolve_fbref_team` is fail-loud → one missing alias silently skips every fixture for that club (this session: ~700 fixtures dropped, mis-reported by the watchdog as "unmatched on FBref"). **Guardrail now exists — USE IT before any backfill:**
- `python -m ingestion.verify_team_aliases "<Comp>"` → checks BOTH spellings (schedule + cached match scoreboxes, per season), prints paste-ready alias lines, exit 1 on any gap.
- Project skill **`verify-team-mappings`** encodes the "0 gaps before backfill" rule.
- Diagnose a stopped run with `grep SKIP backfill.log`.

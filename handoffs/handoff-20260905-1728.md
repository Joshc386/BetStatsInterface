## Two things the 01/09 handoff framed wrongly

Both were corrected from the data, and both change the conclusion rather than a
detail. Worth knowing before re-reading that document.

1. **`average` was not the suspect — it was the only correct one.** 01/09 read
   the disagreement as "`per_90` is deflated because it uses a different
   denominator to `average`". The measurement inverts it: NULL means *the source
   did not publish the column*, so **both** `per_appearance` and `per_90` were
   wrong and `average` was right. Proof is page-level: the five affected columns
   are always NULL together (zero rows disagree), and of 10,617 fixtures 9,253
   are fully populated, 1,364 fully NULL, **none mixed**.
2. **`CLAUDE.md` was wrong about the cause.** "34 FA Cup fixtures" is exact but
   2.5% of it; **95.6% is minor-confederation international qualifiers**, the
   sparsity ADR 0011 had already accepted knowingly. `CLAUDE.md` is now
   corrected.

## Standing gotchas (this session's additions in bold)
- **A pathless `git commit` takes everything staged — an earlier `git rm` swept a
  file deletion into an unrelated commit. Check `git show --stat` after
  committing, not just `git status` before.**
- **Browser-pane screenshots time out when the window is behind another; fall
  back to `get_page_text` / `javascript_tool`, which work fine.**
- **`Competition.type`, not `.competition_type` (that name is on the fact rows).**
- Read the digest with dates in mind — it reports history, not just live faults.
- `&&` is a parse error in PowerShell 5.1.
- `pytest` piped to `tail` hangs — redirect to a file.
- `uvicorn --reload` and Vite HMR are unreliable under OneDrive.
- Repo-wide `grep` over the tree is slow enough to time out — use the Grep tool.
- MCP `postgres` points at the wrong DB — query via `backend/.venv` +
  `SessionLocal()`.
- `.gitignore` covers `*.log` but not `*.txt`.
